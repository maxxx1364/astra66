## من کی‌ام و چی می‌خوام
- من ایرانم، سرمایه‌م کمه و نمی‌خوام پولی رو روی روشی بذارم که با داده ثابت نشده.
- هدف فعلی: اکسپرت متاتریدر ۵ خودم به اسم **Solin_Pilot** روی **طلا (XAUUSD)**. می‌خوام:
  1. بهترین و **پایدارترین** ورودی‌هاش پیدا بشه
  2. یه **لایه‌ی دفاعی (فیلتر)** روش اضافه بشه که معامله‌های بد رو رد کنه
- جواب‌ها رو **فارسی، ساده و صریح** بده، بدون حرف دوپهلو. اگه چیزی کار نمی‌کنه، رک بگو.

## قانون‌های سخت (مهم‌تر از همه)
1. **هیچ عددی رو از خودت نساز.** هر نتیجه‌ای باید از اجرای واقعی بیاد. اگه چیزی رو اجرا نکردی، بگو اجرا نشده.
2. **آموزش/آزمون جدا:** هر ورودی یا فیلتری فقط روی دوره‌ی آموزش انتخاب بشه و روی دوره‌ی آزمون **یک بار** سنجیده بشه. پیشنهاد: آموزش ۲۰۱۸ تا ۲۰۲۳، آزمون ۲۰۲۴ تا امروز.
3. **پایداری مهم‌تر از اوج سوده.** ورودی‌ای رو انتخاب کن که توی یه محدوده‌ی پهن از مقادیر خوب کار کنه، نه فقط روی یه عدد خاص.
4. **کارمزد، اسپرد و سواپ واقعی بروکر** توی همه‌ی نتیجه‌ها حساب بشه.
5. منطق معاملاتی اکسپرت رو بدون اجازه‌ی من تغییر نده. فیلترهای جدید **ورودی (input) قابل خاموش/روشن** باشن.

## وضعیت اکسپرت Solin_Pilot
- فایل: `C:\trading\Solin_Pilot.mq5` (نسخه‌ی **4.01**). این نسخه فقط یه چیز به نسخه‌ی اصلی 4.00 اضافه داره: ورودی **`InpLogTrades`** (پیش‌فرض روشن، فقط در Strategy Tester). منطق معاملاتی دست نخورده. **هنوز کامپایل نشده.** اول کامپایلش کن و اگه خطا داشت، رفعش کن.
- با `InpLogTrades`، آخر هر بک‌تست فایل `solin_XAUUSD_PERIOD_xx_trades.csv` در `Common\Files` متاتریدر نوشته می‌شه. برای هر معامله‌ی بسته‌شده یک ردیف داره: موتور، نوع ورود، جهت، زمان‌ها، سود خالص، **R-multiple**، و ۲۲ ویژگی بازار لحظه‌ی ورود (ساعت، روز هفته، stateA/B، رنگ‌ها، risk_atr، atr_dr، er30، slope96، dist96، dist24، cloud_w، piv_dist، touches، respect، rv، rm، delta، ret12، spread).
- اکسپرت ۴ موتور داره:
  - **A ابر:** روی M15، M30 و H1. پیش‌فرض روشن.
  - **B پیوت:** روی M30. پیش‌فرض خاموش.
  - **C اوردربلاک:** روی M30. پیش‌فرض روشن.
  - **D خط روند:** پیش‌فرض خاموش.
- **این اکسپرت اسکالپر نیست،** نوسان‌گیر M15 تا H1 هست.

## نکته‌هایی که از خوندن کد پیدا شد
- بعضی ورودی‌ها طبق کامنت خود کد روی **کل ۲۰۱۸ تا ۲۰۲۶** بهینه شدن، مثل `InpC_TrailATR=3.25` و `InpC_BreakevenR=1.5`. یعنی نتیجه‌ی بک‌تستشون خوش‌بینانه‌ست و باید با آموزش/آزمون جدا دوباره بررسی بشن.
- هر موتور جدا `InpRiskPercent` (۱٪) ریسک می‌کنه. موتور A و C روی M30 با هم می‌تونن تا ۲٪ ریسک هم‌زمان داشته باشن.
- ریسک اولیه از کامنت معامله (`r=`) خونده می‌شه. اگه بروکر کامنت رو کوتاه یا پاک کنه، breakeven و قفل سود **بی‌صدا خاموش می‌شن.** این رو روی حساب واقعی چک کن.

## کارهایی که باید انجام بدی (به ترتیب)
1. `Solin_Pilot.mq5` رو کامپایل کن و خطاها رو رفع کن.
2. **بک‌تست با تنظیمات فعلی:** XAUUSD، ۲۰۱۸ تا امروز، مدل **Every tick based on real ticks**:
   - روی **M30** (موتور A و C)
   - روی **H1** (موتور A)

   اگه می‌تونی تستر رو خودکار با `terminal64.exe /config:tester.ini` اجرا کن. اگه نشد، از من بخواه دستی اجرا کنم.
3. فایل‌های `trades.csv` رو با اسکریپت `solin_trade_analysis.py` تحلیل کن (بخش پایین):
   ```
   python solin_trade_analysis.py <مسیر trades.csv> --split 2024-01-01
   ```
4. گزارش بده:
   - نتیجه‌ی هر موتور و هر نوع ورود، جدا برای آموزش و آزمون
   - کدوم ویژگی‌ها **توی هر دو دوره** معامله‌ی سودده رو از ضررده جدا می‌کنن (AUC)
5. فقط فیلترهایی که توی هر دو دوره پایدارن رو به‌صورت input جدید (پیش‌فرض خاموش) به اکسپرت اضافه کن. بعد با بک‌تست واقعی روی دوره‌ی آزمون نشون بده چه اثری دارن.
6. برای بهینه‌سازی ورودی‌ها، از Optimization متاتریدر با **Forward = 1/3** استفاده کن. از بین نتیجه‌ها، **ناحیه‌ی پایدار** رو انتخاب کن، نه تک‌نقطه‌ی بهترین.
7. **بعداً، فقط اگه فیلتر عددی جواب داد و من خواستم:** لایه‌ی Claude رو آزمون کن، یعنی اکسپرت از طریق WebRequest از Claude تأیید ورود بگیره. نکته‌هاش:
   - WebRequest توی Strategy Tester کار نمی‌کنه، پس آزمونش باید آفلاین روی همین `trades.csv` انجام بشه.
   - تاریخ و قیمت مطلق نباید به Claude داده بشه، تا از حافظه‌ش استفاده نکنه.
   - آزمون نهایی فقط روی داده‌ی بعد از پایان دانش مدل.
   - نسخه‌ی مدل قفل بشه و دما صفر باشه.
   - اگه API جواب نداد، معامله‌ی جدید باز نشه.
   - هزینه، تأخیر و شرایط استفاده از API رو هم بررسی کن.
