# نصب روی ویندوز سرور: سیستم زنده + متاتریدر ۵

یک سرور ویندوز با IP ایران سه کار انجام می‌دهد:

1. **سیستم زنده‌ی اسپات** (`live/`) به‌صورت سرویس همیشه‌روشن
2. **متاتریدر ۵** با اکسپرت `mt5/TBAE_EdgeEA.mq5`
3. **محیط توسعه:** Claude مستقیم روی همین سرور تست و به‌روزرسانی می‌کند

> این اسکریپت‌ها روی ویندوز واقعی تست نشده‌اند (محیط توسعه لینوکسی است). اولین
> نصب را قدم‌به‌قدم انجام بده و هر خطایی دیدی، متن کاملش را بفرست.

## مشخصات سرور

|---|---|---|
| رم | ۴ گیگ | **۶ تا ۸ گیگ** (ویندوز، متاتریدر، سیستم و Claude کنار هم) |

## ۱. نصب پیش‌نیازها (یک بار)

1. **Python 3.12** (۶۴ بیتی) از python.org. موقع نصب گزینه‌ی **Add python.exe to PATH** را بزن.
2. **Git for Windows**.
3. دریافت پروژه:
   ```powershell
   cd C:\
   git clone https://github.com/maxxx1364/astra66.git
   cd C:\astra66\tbae
   ```
4. **Windows Update:** در Settings ← Windows Update ← Active hours، کل ساعت‌های معامله را
   فعال بگذار تا سرور وسط معامله خودبه‌خود ری‌استارت نشود.

## ۲. نصب سیستم زنده

در PowerShell با دسترسی Administrator:

```powershell
cd C:\astra66\tbae
powershell -ExecutionPolicy Bypass -File deploy\windows\install.ps1
```

این اسکریپت:

* محیط پایتون و کتابخانه‌ها را نصب می‌کند
* پوشه‌ی `C:\tbae` را می‌سازد: تنظیمات (`live.json`)، کلیدها (`live.env`)، دیتابیس و لاگ
* یک Scheduled Task به اسم `TBAE-Live` ثبت می‌کند که با روشن شدن سرور اجرا می‌شود،
  بدون نیاز به لاگین کار می‌کند و اگر بیفتد خودش دوباره بالا می‌آید

بعد از نصب، داخل سرور (از طریق RDP) در مرورگر برو به **http://127.0.0.1:8100**.
لاگ‌ها در `C:\tbae\logs\live.log` ذخیره می‌شوند.

اگر pip نتوانست کتابخانه‌ها را دانلود کند (اختلال اینترنت بین‌الملل)، متن خطا را بفرست.

## ۳. متاتریدر ۵

متاتریدر برنامه‌ی گرافیکی است و فقط وقتی کار می‌کند که یک کاربر لاگین باشد:

1. متاتریدر ۵ را نصب کن و با حساب بروکر وارد شو. فایل `mt5/TBAE_EdgeEA.mq5` را طبق
   `mt5/README.md` اضافه کن.
2. **لاگین خودکار ویندوز** (تا بعد از ری‌استارت، متاتریدر خودش بالا بیاید): با
   `Autologon` از Microsoft Sysinternals.
3. میان‌بر متاتریدر را در پوشه‌ی Startup بگذار: `Win+R` ← `shell:startup`.
4. **پنجره‌ی RDP را با Disconnect ببند، نه Sign out.** با Sign out، متاتریدر بسته می‌شود.
5. **حد ضرر و حد سود را حتماً روی خود معامله ست کن.** این‌ها روی سرور بروکر ذخیره
   می‌شوند، پس اگر سرور ما یا اینترنت قطع شود هم معامله بسته می‌شود.

## ۴. به‌روزرسانی

```powershell
cd C:\astra66\tbae
powershell -ExecutionPolicy Bypass -File deploy\windows\update.ps1
```

این اسکریپت کد جدید را می‌گیرد و **همه‌ی تست‌ها را اجرا می‌کند**. فقط اگر تست‌ها پاس
شوند سیستم را ری‌استارت می‌کند، پس یک تغییر خراب هیچ‌وقت جای نسخه‌ی سالم را نمی‌گیرد.

## ۵. ارتقای سریع‌تر: اتصال Claude به سرور

بیشترین سرعت وقتی است که Claude مستقیم روی سرور کار کند. یعنی اتصال واقعی به تبدیل
را تست کند، لاگ‌ها را بخواند و خطاها را همان‌جا رفع کند، بدون اینکه تو چیزی کپی کنی.

1. روی سرور **Claude Desktop** را نصب کن و وارد حسابت شو.
2. در Settings ← Claude Code ← Remote Control، پوشه‌ی `C:\astra66\tbae` را اضافه کن.
   (یا در PowerShell داخل همان پوشه: `claude remote-control`.)
3. به Claude بگو «سرور وصل است». Claude درخواست اتصال می‌فرستد و تو تأیید می‌کنی.

هر بار اتصال را خودت تأیید می‌کنی و هر وقت بخواهی می‌توانی قطعش کنی. همه‌ی نسخه‌های
ویندوز از این قابلیت پشتیبانی نمی‌کنند. اگر پوشه در فهرست ظاهر نشد، خبر بده.

## امنیت

* داشبورد فقط روی `127.0.0.1` باز است. از داخل RDP ببینش و پورت ۸۱۰۰ را در فایروال باز نکن.
* کلیدهای API فقط در `C:\tbae\live.env` قرار می‌گیرند. دسترسی به این فایل فقط برای
  Administrators و SYSTEM است و در گیت ذخیره نمی‌شود.
* برای RDP رمز قوی بگذار. اگر ارائه‌دهنده‌ی سرور امکانش را دارد، پورت RDP را عوض کن یا
  دسترسی را به IP خودت محدود کن.
